## Critical Mode A — panel off, mirroring active

Keep a non-sensitive, visibly updating app open. Put the phone where its panel is observable. Use a second camera or tester notes if needed; do not upload phone content.

| ID | Procedure | Expected evidence |
|---|---|---|
| A01 | Start with screen-off enabled | Physical panel becomes off while fresh video frames continue in desktop window |
| A02 | While panel off, tap/scroll/type from desktop for at least 5 minutes | Ongoing video and supported mouse/keyboard actions, no unexpected lock; record existing phone timeout/charging state |
| A03 | Use Display on | Physical panel restores; desktop video continues; not confused with unlocking |
| A04 | Start normally; use Display off during session | Same panel-off/stream behavior without restarting scrcpy |
| A05 | Direct scrcpy Right Ctrl+O / Right Ctrl+Shift+O | Confirms documented engine mechanism separately from AirMirror's Windows focus adapter |
| A06 | Hold a physical modifier while clicking display controls | AirMirror refuses ambiguous injection and gives useful guidance; no stuck keys |
| A07 | Move focus rapidly / test focus restriction | Action goes only to owned scrcpy or reports blocked; no unrelated typing |
| A08 | While off, stop mirror or disconnect Wi-Fi | Owned process is cleaned up; physical power button restores display if software cannot; record actual OEM behavior |
| A09 | Repeat A01–A08 on battery and while charging | Record any difference; do not assume stay-awake works wirelessly on battery |

A01–A04 are required before claiming the Samsung Galaxy F15 physical-screen-off requirement is validated. Shortcut delivery alone is not evidence of physical display state or ongoing capture.
